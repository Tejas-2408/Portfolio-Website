# Tejas Bansal — Portfolio

Personal portfolio and freelance business site for **Tejas Bansal** — freelance
website developer, API integration specialist and AI automation builder.
Live at [tjcr.in](https://tjcr.in).

Built with **TanStack Start**, **React 19**, **TypeScript** and **Tailwind CSS**,
and deployed on Cloudflare.

## ✨ Features

- Fully responsive, dark/light mode, SEO-optimized (meta tags, JSON-LD, sitemap)
- Sections: Hero, About, Services, Skills, Projects, **Freelance Work Showcase**,
  Experience, FAQ, Contact
- Contact form powered by [FormSubmit](https://formsubmit.co)
- **Live client work showcase** with **client testimonials synced from Google Sheets**
  (see [Freelance Work & Testimonials](#-freelance-work--testimonials) below)
- Single source of truth for all content in `src/data/portfolio.ts`

## 🧱 Tech Stack

| Layer | Tech |
| --- | --- |
| Framework | [TanStack Start](https://tanstack.com/start) (file-based routing, SSR) |
| UI | React 19, Tailwind CSS 4, Radix UI, shadcn-style components |
| Language | TypeScript |

## 🚀 Getting Started

### Prerequisites

- [Bun](https://bun.sh) installed (recommended), or Node.js 18+ with npm

### Install & run

```bash
# install dependencies
bun install        # or: npm install

# start the dev server
bun dev             # or: npm run dev

# build for production
bun run build        # or: npm run build

# preview the production build locally
bun run preview      # or: npm run preview

# lint / format
bun run lint          # or: npm run lint
bun run format        # or: npm run format
```

The dev server runs at `http://localhost:3000` by default.

## ✏️ Editing Content

Almost everything on the site (name, bio, services, skills, projects, FAQs,
contact email, social links) is defined in **`src/data/portfolio.ts`**.
Update that file and the whole site updates — no need to touch component code.

Key fields:

```ts
export const profile = {
  name: "Tejas Bansal",
  email: "creative@tjcr.in",   // used in the contact form, JSON-LD & footer
  ...
};

export const links = {
  github: "...",
  linkedin: "...",
  leetcode: "...",
  siteUrl: "https://tjcr.in",
};
```

## 💼 Freelance Work & Testimonials

The **"Freelance work"** section (`src/components/portfolio/Showcase.tsx`,
rendered at `#showcase`) has two parts:

### 1. Live client work

A simple, hand-maintained list in `src/data/portfolio.ts`:

```ts
export const freelanceWork = [
  {
    client: "Client or project name",
    title: "Short project title",
    description: "One or two lines about what was built.",
    url: "https://the-live-site.com",
    tags: ["React", "Tailwind CSS", "..."],
  },
];
```

Add a new object to this array every time you ship a freelance project —
it appears on the site immediately, no other changes needed.

### 2. Client testimonials — synced live from Google Sheets

Testimonials are pulled at runtime from a Google Sheet, so you (or a client)
can add a review to the sheet and it shows up on the site automatically,
**no code changes or redeploys required**.

**Setup:**

1. Create a Google Sheet with these column headers in row 1 (order doesn't
   matter, names are case-insensitive):

   | name | role | company | quote | rating | avatarUrl | projectUrl |
   | --- | --- | --- | --- | --- | --- | --- |
   | Priya Sharma | Founder | Acme Co. | Delivered ahead of schedule... | 5 | https://... | https://... |

   Only `name` and `quote` are required — the rest are optional.

2. In Google Sheets: **File → Share → Publish to web**.
3. Under "Link", choose the specific sheet/tab, set the format to
   **Comma-separated values (.csv)**, then click **Publish**.
4. Copy the generated URL (looks like
   `https://docs.google.com/spreadsheets/d/e/.../pub?output=csv`).
5. Paste it into `src/data/portfolio.ts`:

   ```ts
   export const testimonialsConfig = {
     testimonialsSheetCsvUrl: "https://docs.google.com/spreadsheets/d/e/.../pub?output=csv",
   };
   ```

6. Redeploy once to add the URL — after that, every new row you add to the
   sheet appears on the live site the next time someone loads the page.

If `testimonialsSheetCsvUrl` is left empty, the section quietly shows a
"no testimonials yet" placeholder instead of breaking the page.

> **Note:** "Publish to web" makes the sheet's data publicly readable via that
> CSV link (not your whole Google account) — don't put anything sensitive in it.

## 📧 Contact Form

The contact form (`src/components/portfolio/Contact.tsx`) submits to
[FormSubmit](https://formsubmit.co) using `profile.email` from
`src/data/portfolio.ts`. The first submission to a new email address requires
one-time confirmation via a link FormSubmit emails to that address — no API
key or backend needed.

## 🌐 Deployment

This project builds to a Cloudflare-ready output via Nitro
(`preset: cloudflare-module`, configured in `vite.config.ts`). Running
`bun run build` produces `.output/` along with a generated
`wrangler.json`, ready to deploy with Wrangler or connect through the
Cloudflare dashboard.
